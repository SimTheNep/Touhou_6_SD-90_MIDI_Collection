Welcome! This repository hosts MIDI arrangements of every track from Touhou 6 (東方紅魔郷).
Each one has been recreated both by ear and via spectrogram for study, eventual SC-88Pro arranges might be added.
Please listen and download freely.
All compositional rights belong to Team Shanghai Alice.
Bug reports and better reproductions are welcome on GitHub.

About this page
Click the at the start of a row to play that track
Click a track name to download its MIDI
Recorded at 44.1Khz 16-bit WAV via SD-90 USB audio, mastered in SonicFoundry SoundForge to -14dB LUFS
Sequenced in Domino MIDI editor with a rough basis on the SC-88Pro soundtrack MIDIs

MIDI made for the SD-90 MIDI made for the SC-88Pro
On other sound sources the sound will not be as intended (e.g. Microsoft GS Wavetable)
The SD-80 works in theory, but it has no AFX unit, so it sounds quite different

☆ Work in progress. These were done by hand, so please be patient with the rough spots ☆
